# SaveAI 🥅🤖

AI-powered goalie video analysis system for ice hockey goaltenders.

SaveAI is a computer vision and deep learning project developed as part of my Bachelor's thesis in Business Information Technology at Haaga-Helia University of Applied Sciences.

The goal of the project is to automate the time-consuming process of hockey goalie video analysis by detecting save situations and generating highlight clips automatically from full-length game footage.

---

## 📖 Thesis Background

Video feedback plays an important role in goalie development, but manually reviewing several hours of game footage is slow and difficult to scale — especially in junior hockey organizations with limited resources.

SaveAI was created to solve this problem by using deep learning and computer vision to:

- Detect goalie save situations automatically
- Analyze hockey game footage frame-by-frame
- Generate ready-to-use save compilation videos
- Reduce manual video editing work for goalie coaches

The project combines:

- Deep learning
- Computer vision
- Object detection
- Sports analytics
- Python automation

This repository contains the prototype implementation developed during the thesis project. These scripts are designed to be ran on google colab.
